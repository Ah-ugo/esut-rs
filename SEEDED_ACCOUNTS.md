### 6. Fast Verification & Testing via API

#### A. Login as Admin
```bash
curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "admin@esut.edu.ng", "password": "admin123"}'
```

#### B. Login as M.Eng Lecturer (e.g. Dr. Gide)
```bash
curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "dr.gide@esut.edu.ng", "password": "lecturer123"}'
```

#### C. Login as Defence Candidate (e.g. Akpata Adaeze Florence)
```bash
curl -X POST "http://localhost:8000/auth/login" \
  -H "Content-Type: application/json" \
  -d '{"email": "adaeze.akpata@pg.esut.edu.ng", "password": "2024070000978"}'
```

#### D. Fetch Academic Transcript
```bash
curl -X GET "http://localhost:8000/transcripts/student/{student_id}" \
  -H "Authorization: Bearer <ACCESS_TOKEN>"
```
